WIP — Work In Progress v1.0.0

功能

  • 周一至周五 + 残留任务六列看板
  • 拖拽改列 / 同列内拖拽排序
  • AI 对话增删改任务（自然语言）
  • 流式输出 + Markdown 渲染
  • 搜索筛选 / 快捷键 / 全局撤销
  • 任务提醒（可选时间+系统通知）
  • 例行任务（每日/每周自动循环）
  • 导出 / 开机自启动
  • 自动跨周结算

⌨ 快捷键

Ctrl+N 新建任务
Ctrl+F 聚焦搜索
Ctrl+Z 撤销操作
Ctrl+Y 重做操作
Enter 发送消息
Shift+Enter 换行
